# Facebook 手动采集 SOP（推广员登录态）

## 为什么需要手动
Facebook 的公开搜索对**匿名访问基本失效**——纯爬/纯 Google 索引只能拿到被搜索引擎收录的少量公开帖。
你们推广员手动能找到，是因为用**自己的登录态**在 Facebook 内搜索。这部分无法由技能自动代跑（也不应代持凭据），所以做成「SOP + 记录模板」，由推广员执行后回填。

## 操作步骤（推广员照做）
1. 打开 Facebook（已登录的工作号/个人号）。
2. 搜索框输入从亚马逊标题推导出的词（不要搜 ASIN）：
   - 第一优先：`<品牌> <产品核心词>`（如 `Boytond AI Translation Earbuds Real Time`）
   - 第二优先：`<品牌>`（看主页/公共主页）
   - 第三优先：`<品牌> discount` / `<品牌> coupon` / `<品牌> giveaway`
3. 在搜索结果里切到「帖子 / 公共主页 / 群组 / 视频」分别看：
   - 帖子：是否带折扣码、是否标记 #ad / 赞助、发布时间
   - 公共主页：是否品牌自营、是否有促销置顶
   - 群组：有没有人在求链接/晒单（需求热度信号）
   - 视频：是否红人测评、描述里有无 affiliate 链接
4. 对每条有用信息：复制链接 + 截图（存到本地，路径记下来）+ 记下折扣码/力度/账号名/日期。

## 回填记录模板（复制到表格或记事本）
```
渠道: Facebook
类型: [帖子/公共主页/群组/视频]
URL:
账号/红人:
标题/摘要:
折扣码:
折扣力度:
日期:
截图路径:
备注:
```
> 技能自动部分产出的报告里，Facebook 手动项会先标「待推广员补充」，推广员回填后合并即可。
